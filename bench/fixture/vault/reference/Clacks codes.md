# Clacks codes

The codes a shift report starts with. See [[ADR-002 Clacks for reports]].

```
GNU  pass it on, do not log, turn at the end of the line
#urgent  a line in a code block is not a tag
[[Ghost note]]  and this is not a link
- [ ] nor is this a task
```

Inline code such as `#not-a-tag` and `[[Not a link]]` does not count either.

| Code | Meaning |
|------|---------|
| WHQ  | to Pseudopolis Yard |
| CST  | to Cable Street |
